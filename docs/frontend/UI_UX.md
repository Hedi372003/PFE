# UI_UX

## Choix de design
- Design moderne et clair, avec cartes, ombres et couleurs douces.
- Utilisation de `Tailwind CSS` pour un style rapide et coherent.
- Palette basee sur bleu, gris et accents.

## Elements UI
- Boutons et inputs reutilisables dans `src/components/ui/`.
- Tables pour les listes (users, robots, requests).
- Modals pour confirmation de suppression et formulaire de reservation.
- Badges de statut pour robots (online, maintenance, offline).

## Animations
- `framer-motion` ajoute des transitions douces.
- Exemple: apparition des cartes, modal de confirmation, toasts.

## Experience utilisateur
- Recherche instantanee sur les listes.
- Feedback visuel pour loading et actions terminees.
- Toasts et messages temporaires pour confirmation.
- Mode sombre active via `Settings` (toggle sur `html.dark`).

## Icones
- `lucide-react` est utilise pour les icones dans les menus et actions.
